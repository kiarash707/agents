# Contributing to K-I Agent

We welcome contributions! See the [docs/](docs/) directory for development guides and architecture decisions.

## Workflow

1. Open an issue or discussion at [GitHub Issues](https://github.com/kiarash707/agents/issues)
2. Fork and create a feature branch
3. Run `npm test` to validate
4. Submit a pull request with a clear description

## Development

- Node.js 20+, npm 9+
- `npm install` then `npm run build`
- See [CLAUDE.md](CLAUDE.md) for agent-driven workflows
- Architecture decisions documented in [docs/](docs/)

## Code of Conduct

Be respectful. See [LICENSE](LICENSE) for terms.
