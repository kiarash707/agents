# 🚀 شروع سریع — فارسی

این راهنما شما را از «هیچ‌چیز ندارم» به «اولین پروژه‌ی راه‌اندازی‌شده» می‌رساند. زمان تقریبی: ۵ تا ۱۰ دقیقه.

---

## ۱. پیش‌نیازها را چک کنید

```bash
node -v    # باید 20 یا بالاتر باشد
npm -v     # باید 9 یا بالاتر باشد
git --version
```

اگر Node 20 را ندارید: از [nodejs.org](https://nodejs.org) نسخه‌ی LTS را نصب کنید.

> 💡 اگر از **Claude Code** یا **Codex** استفاده می‌کنید، آن‌ها را هم نصب داشته باشید (دستیار اصلی شماست؛ K-I Agent لایه‌ی هماهنگی دور همان است).

---

## ۲. نصب K-I Agent

```bash
# کپی مخزن
git clone https://github.com/kiarash707/agents.git k-i-agent
cd k-i-agent

# نصب وابستگی‌ها
npm install

# فعال‌سازی خط فرمان (یک‌بار)
npm link
```

از این پس دستور `k-i-agent` در همه‌ی محل‌ها در دسترس است.

---

## ۳. اولین راه‌اندازی

پروژه‌ی آزمایشی بسازید (روی پروژه‌ی مهم‌تان مستقیم شروع نکنید):

```bash
mkdir ~/my-test-project && cd ~/my-test-project
k-i-agent init
```

دستیار تعاملی از شما می‌پرسد:

- برای کدام دستیار راه‌اندازی کنیم؟ (Claude Code / Codex / هر دو)
- کدام پلاگین‌ها فعال باشند؟
- سطح جزئیات گزارش‌دهی؟

پس از اتمام، فایل‌هایی مثل `.claude/` و `CLAUDE.md` در پروژه ساخته می‌شود. **یک‌بار لیست تغییرات را نگاه کنید** (با `git status` اگر git دارید).

---

## ۴. بررسی سلامت

```bash
k-i-agent doctor
```

بررسی می‌شود: نسخه Node، دسترسی به MCP، پایگاه حافظه، کلیدهای API، فضای دیسک و ... اگر چیزی قرمز بود، خروجی `doctor` راه‌حل پیشنهادی می‌دهد. برای اجرای خودکار پیشنهادها:

```bash
k-i-agent doctor --fix
```

---

## ۵. اولین کار با دستیار

حالا مثل همیشه Claude Code را باز کنید و یک وظیفه‌ی کوچک بدهید:

> «نقشه‌ای از ساختار این پروژه به من بده: فایل‌های اصلی، نقطه‌ی ورودی و چطور تست‌ها اجرا می‌شوند. در همین نشست فقط خواندنی (read-only) بمان.»

اگر از پلاگین‌ها استفاده می‌کنید، دستورهای Slash (مثل `/status`) هم در دسترس‌اند.

---

## ۶. اتصال MCP (اختیاری، برای کانال‌های دیگر)

اگر می‌خواهید MCP سرور را مستقیم به Claude Code یا Codex وصل کنید:

```bash
# Claude Code
claude mcp add k-i-agent -- npx --yes k-i-agent mcp start
claude mcp list

# Codex CLI
codex mcp add k-i-agent -- npx --yes k-i-agent mcp start
codex mcp list
```

بعد از اتصال، یک ابزار بی‌خطر (مثلاً health check) را صدا بزنید و **خروجی واقعی** را ببینید — ثبت‌شدن ابزار، یعنی وصل‌شدن نیست.

---

## ۷. نصب سبک با پلاگین (بدون `init`)

اگر نمی‌خواهید فایل‌های پیکربندی در پروژه‌ات ساخته شود:

```
# داخل Claude Code
/plugin marketplace add kiarash707/agents
/plugin install ruflo-core@k-i-agent
```

این مسیر فقط دستورهای Slash و تعریف عامل‌ها را اضافه می‌کند؛ هوک‌ها و کارکنان پس‌زمینه را اضافه **نمی‌کند**.

---

## ✅ آزمون پذیرش (مهم‌ترین بخش)

پروژه‌ی شما «راه‌اندازی‌شده» است وقتی:

- [ ] `k-i-agent doctor` همه‌ی سطوح مهم را سبز می‌دهد
- [ ] دستیار شما یک ابزار (مثلاً health) را **واقعاً** اجرا کرده و خروجی دیده‌اید
- [ ] یک حافظه‌ی ساده ذخیره و در نشست جدید بازیابی شده است
- [ ] می‌دانید دقیقاً چه فایل‌هایی در پروژه اضافه شده‌اند

---

## ❓ مشکلات رایج

| مشکل | راه‌حل |
|------|-------|
| `npm install` خطای بیلد (better-sqlite3 و ...) می‌دهد | Node 20+ و toolchain C++ (با VS Build Tools روی ویندوز) لازم است؛ یا `--ignore-scripts` برای شروع سبک |
| `k-i-agent: command not found` | `npm link` را دوباره در ریشه‌ی مخزن اجرا کنید |
| دستیار MCP را نمی‌بیند | `mcp list` را در همان دستیار اجرا کنید؛ پورت و مسیر Node را چک کنید؛ دستیار را ریستارت کنید |
| `init` فایل‌های غیرمنتظره ساخت | پروفایل install را از «minimal» شروع کنید و با `doctor` وضعیت را ببینید |
