## اگر عجله دارید

سه دستور:

```bash
git clone https://github.com/kiarash707/agents.git k-i-agent
cd k-i-agent && npm install && npm link
k-i-agent init
```

بعد از آن، فقط مثل همیشه از Claude Code یا Codex استفاده کنید — هماهنگی، حافظه و یادگیری در پس‌زمینه اتفاق می‌افتد.
